# A live memory field, not another generic dashboard

Accepted. Buildless same-origin HTML/CSS/JS renders a field of real shard lock domains beside actual command execution. Charcoal/olive cells and orange selection distinguish it from the other flagships. Large type introduces the task; the map, inventory and quota/chain inspector do the work. No fake activity pulse, generated throughput chart or random values. The visual reference is memory-space inspection: [Valgrind Massif](https://valgrind.org/docs/manual/ms-manual.html) distinguishes useful payload from allocation overhead. The viewer borrows that explanatory distinction, not its code, assets or layout. System fonts only.

Use a fixed worker pool and bounded queues for portable POSIX networking. This is easy to inspect but idle clients consume workers and the periodic sweeper can contend with traffic. An event loop and incremental expiry would be a separate measured change. No accounts or deployment are created by the demo.
